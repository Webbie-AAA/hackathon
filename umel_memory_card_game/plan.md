Memory Card Game

How cards are presented on the terminal:

Back of cards:
`+-------+ +-------+ +-------+ +-------+
|       | |       | |       | |       |
|   0   | |   1   | |   2   | |   3   |
|       | |       | |       | |       |
+-------+ +-------+ +-------+ +-------+`,
`+-------+ +-------+ +-------+ +-------+
|       | |       | |       | |       |
|   4   | |   5   | |   6   | |   7   |
|       | |       | |       | |       |
+-------+ +-------+ +-------+ +-------+`,

Step by step breakdown of the game:

1. First all 7 cards will display on the terminal.

2. The user will be prompted to pick 2 numbers from 0 to 7. As per the card.

3. If they don't get a match its the computers turn.

4. If its a match:
    - they get an additional point
    - The image of the card pair they got is displayed
    - As well as appended to their array is the card pair in a nested array
    
5. Then its the computers turn. 

5. The end is when the all four matches have been made

6. The winner is the one with the most pairs matched

7. If it's a draw, it's a draw - nothing happens.
